# Banning Simulator X

A Roblox simulator game

### Building

To build the project, install [Foreman](https://github.com/Roblox/foreman) and [roblox-ts](https://github.com/roblox-ts/roblox-ts/blob/master/CONTRIBUTING.md), then run

```sh
npm run build
```

to compile the source code. You can then sync the code over to Roblox Studio by running

```sh
rojo serve
```

and connecting to the rojo server.
